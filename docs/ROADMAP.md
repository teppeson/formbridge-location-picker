# PJ033 FormBridge Location Picker Roadmap

本書は、このプロジェクトの方向性と未決事項を利用者・外部開発者へ示すための文書です。
日々の作業進捗やセッション単位の状態は本書では管理しません。

## 目的とゴール

- 最終ゴール: 既存利用者との後方互換性を最優先に、調査・実装・テスト・Pull Request準備を
  エージェントが主導し、Humanが理解したうえで公開を承認できる継続的な開発体制を確立する。
- 成功条件:
  - v13の主要挙動が互換性仕様として記録される。
  - lintと自動テストをローカルおよびCIで再現できる。
  - Human承認なしにmain、公開Release、既存利用者の動作へ影響を与えない。
  - 変更理由、検証結果、戻し方をPull Requestで説明できる。
- 明確な非ゴール:
  - 短期間で新機能版を公開すること。
  - 基盤整備と同時に本体JavaScriptをリファクタリングすること。
  - 実FormBridge環境の確認を自動テストだけで代替すること。

## 現在の方針

- 最優先: 既存利用者保護とv13の後方互換性。
- 開発方式: エージェント主導・Human公開承認。main直接編集は禁止し、ブランチとPull Requestを使用する。
- 公開履歴の方針: 1つの論理的変更を1つのPull Requestとし、squash mergeでmainへ取り込む。
  詳細は`docs/RELEASE_PROCESS.md`。
- 実装方針: 配布ファイルの形式と本体動作を不必要に変えず、開発用の安全網から追加する。
- 見直し条件: FormBridge仕様変更、重大な脆弱性、現行v13では解決不能な互換性問題が判明した場合。
